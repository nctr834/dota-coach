# Dota Draft Analyzer

## Architecture
- **API**: FastAPI backend (`api/main.py`) — serves on `:8000`
- **Analyzer**: Core logic (`analyzer/`) — `evaluator.py` (draft scoring), `counters.py` (matchup math), `process_query.py` (LLM context building)
- **Frontend**: React + Vite + Tailwind (`frontend/`) — proxies `/api` to backend
- **Data Pipeline**: `scripts/gather_data.py` — pulls from Stratz, d2vpkr, OpenDota
- **GSI**: Game State Integration (`gsi/`) — exists but not wired into query pipeline yet
- **Data**: JSON files in `data/` (gitignored, generated by scripts)

## Commands
```bash
# Backend
python3 api/main.py                    # Start API server
# or: uvicorn api.main:app --reload

# Frontend (run gather_data.py first: it generates the gitignored
# frontend/src/data/hero_data.json that the UI imports at build time)
cd frontend && npm run dev             # Start dev server (Vite)
cd frontend && npm run build           # Production build
cd frontend && npm run lint            # ESLint

# Data pipeline
python3 scripts/gather_data.py         # Refresh all data from APIs

# Smoke test (imports, data, draft math, OpenDota tools; no LLM calls)
python3 scripts/smoke_test.py
```

## Code Style
- **Python**: Black formatter (line-length 88, Python 3.12). Pre-commit hook runs Black automatically.
- **JS/JSX**: ESLint with react-hooks + react-refresh plugins
- No test suite exists yet

## Critical Constraints
- **LLM is a formatter, not a game expert.** Haiku formats output only — never trust it for Dota game knowledge. It gives confidently wrong advice.
- **Draft scoring is math-backed** (`evaluator.py`). Don't change the scoring math without discussing first.
- **Item display names** need manual overrides (`ITEM_NAME_OVERRIDES` in `gather_data.py`) — Valve's localization files are incomplete.
- **Item builds** filtered to >5% pick rate to eliminate noise.
- `.env` contains `STRATZ_API_KEY` and `ANTHROPIC_API_KEY` — never read or commit this file.

## Data Sources
- **Stratz GraphQL API** — hero matchups, position win rates (requires `STRATZ_API_KEY`)
- **d2vpkr** — Valve game files: abilities, items, patch notes, localization (GitHub raw)
- **OpenDota API** — item build popularity from pro games (no auth)
- **Coach transcripts** — `data/transcripts_condensed/` (BSJ, PainDota, ZQuixotix)
